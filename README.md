# Global Comex 

Crie um novo projeto chamado “Global Comex | Redesign”.

CONTEXTO

Este projeto é uma modernização do site existente da Global Comex Assessoria Aduaneira Ltda.

Site atual:
https://global-comex.com

A Global Comex já possui um site institucional completo. O cliente não quer uma empresa nova, uma nova identidade ou uma mudança radical de conteúdo.

O objetivo é fazer o site atual parecer uma evolução de várias gerações: mais moderno, mais vivo, mais sofisticado, mais robusto, mais interativo e visualmente muito mais impactante.

A frase que resume o objetivo visual é:

“É a Global Comex, só que agora o site tem vida.”

IMPORTANTE: NÃO criar um site completamente diferente.
É uma EVOLUÇÃO VISUAL E EXPERIENCIAL do site existente.
